// LINKLENS HEURISTIC THREAT SPECIFICATION

MISSION DIRECTIVE: "PAUSE BEFORE YOU CLICK"

LinkLens is an educational cybersecurity tool designed to help users identify deceptive URL structures before interacting with suspicious links in emails, SMS phishing (smishing), or chat messages.

LOCAL HEURISTIC SCORING ENGINE

Our scoring engine computes a composite risk rating between 0 and 100 across structural checks, including authority deception (@ credentials), IP-based hosts, punycode homographs, deep subdomain camouflage, known shorteners, and external redirect parameters.

HEURISTIC THREAT RATINGS

  • 0–24: No Obvious Warning Signs Detected — No common deceptive structural patterns identified. This does not guarantee safety.
  • 25–54: Some Warning Signs — Non-standard elements detected (such as URL shorteners or potential open redirect parameters). Review carefully.
  • 55–100: High Concern — Multiple severe deceptive structures or authority masquerades identified.

CRITICAL BOUNDARIES & DISCLAIMER

Absence of warning signs is not proof of safety. LinkLens operates purely on local URL grammar and static heuristics. It does not inspect destination server code or live malware payloads.

PRIVACY GUARANTEE

Zero network traffic. Links are parsed strictly in local browser memory. Sensitive authentication credentials and session tokens are redacted automatically.
